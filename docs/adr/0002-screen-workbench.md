# 对照页是本机只读双栏工作台

对照页给本人看停驻、圈岗，一次只看一处，默认先看保留（无则待读）。快捷键 1~4 依次对应保留、待读、AI、规则。打开时选定最近改过的一份筛选结果，下拉另选；不跟踪正在写入的文件，不改配置。圈岗只留在本机。读哪些目录见 ADR 0007。

版式是左右双栏：左栏高密度岗位流，取消视口硬分页；右栏常驻岗位元数据、四维 AI 评语与原始 JD 全文对照，取消行内展开。岗位名带 Boss 链接与直达动作。规则与淘汰自适应兼容展示。圈岗在左侧卡片最左。页上不改淘汰。

**Code**: `screen/`

**Considered Options**: 四处并排；默认规则；跟着筛选过程刷新；把多份结果合成一岗再看；页上改搜词或启停；一行一个岗多栏网格加行内展开；表头加分页器；三栏式导航；两栏并列 Tabs 切换。
