# 对照页是本仓独立工作台

对照页给本人审停驻、顺手圈岗。本仓 `screen/` 是独立 Vite 页，打开 `http://localhost:6867`，数据只读 `boss/` `:9527`。无筛选服务配置壳。顶上城市分页 + 四处停驻计数，一次只展开一处。默认打开规则。打开时选定最近改过的一份筛选结果，下拉切换，不跟踪正在写入的文件，不改 yaml。圈岗只是本机标记。行怎么排见 ADR 0003。这是个人工具页：不加跟跑、并看、自动去重这类模式。

**Code**: `screen/`

**Considered Options**: 四段看板并排；卡片；虚拟长列表；默认打开保留；仍在 get_jobs/front 换皮；仓外第三份目录；对照页跟配置页同一套 ThemeProvider。
