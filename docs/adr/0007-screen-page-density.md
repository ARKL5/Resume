# 对照页去掉说明，岗位名即 Boss 链接

对照页只给本人用，不写已经理解的标题和漏斗说明。打开就是城、停驻计数、搜索/已圈、岗。一行两行：岗位名（Boss 链接）+ 公司 + 地点/活跃同一行，停因第二行。无列头。已拉到的 JD 用 `d` 展开。按停因归堆的分组条留下。宽屏两列，再宽三列，窄屏一列。一页条数 = 列数 × 能铺满视口的行数。条数填不满时不留空列格子、不撑大框，底下是纸面。圈岗仍在最左。不在页上改淘汰。圈阅视觉见 ADR 0009。

**Code**: `screen/`

**Considered Options**: 七列表头；公司名做主标题；行上「JD」按钮；去掉停因分组条。
