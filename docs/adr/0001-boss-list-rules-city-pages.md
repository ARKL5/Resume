# 列表上筛选，城市只分页

字面、黑名单和招聘者头衔只在列表上判断；城市只分页，不建区县表，也不因城市淘汰。标题 AI 三态，判成可点也不等于点开详情，其它城不点。每个搜词滚到底。同一轮共用一个时间戳，一搜词一份 jsonl，只追加，主键是 encryptId。stage 字段见 ADR 0003。搜词和筛选条件改 `boss.yaml`。

HR 活跃以详情为准，是列表规则的例外：列表上的活跃文案经常是空的，空文案不淘汰；点开详情后用详情里的文案，有字且不是近 3 天就按规则淘汰，不送 JD AI。已记保留的岗下次再见到、存着的文案不是近 3 天，在新文件里改判为规则淘汰。

**Code**: `src/boss_screen/rules.py`、`src/boss_screen/run.py`

**Considered Options**: 进详情后再用城市或标题字面淘汰；列表只滚前 50；在代码里写死详情次数；只修列表抓取、详情仍不看活跃；列表上空文案直接淘汰。
