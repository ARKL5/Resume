# 国内实习投递：辅助浏览器插件 / 油猴脚本 / 海投扩展 / 官方填表插件

- 调研日期：2026-09-18
- 承接：`.notes/internship-batch-apply-cn.md` 第 3.B 节
- 范围：只讨论「填表 / 点提交 / 自动打招呼 / 自动回复 HR」。不代替面试。不把自动沟通包装成合法投递。
- 方法：打开 Chrome 商店页、Edge 商店页、产品官网、GitHub README / LICENSE、平台用户协议。二手帖只当线索，不当前提。
- 硬约束：不写可运行自动化代码、CSS 选择器、接口签名、验证码绕过；不登录用户账号；不替人投递；不教规避检测。
- 证据规则：每个事实主张回溯到下面列出的一手来源。搜不到就写「未找到」，不编。

「官方」= 该招聘平台或该简历产品自己发布、自己背书的功能。  
「第三方」= 不是目标招聘平台发布的扩展、脚本、桌面客户端、代投服务。  
「仅填表」= 公开描述是把已有信息填进表单，提交仍须本人点。  
「代提交 / 代聊」= 公开描述会替用户点投递、点立即沟通、发招呼语、或自动回复 HR。

### 2.5 这四段合在一起的含义（不是用法）

- **禁的是未经许可的第三方工具接入**，包括浏览职位、收发简历、自动登录。协议没有写「看起来像人手点就可以」。
- 平台**自己**发的插件（牛客网申助手、实习僧网申助手）或**自己**产品里的自动投（智联智能投递、Boss 网申·直投）不落在「未经许可的第三方」里。
- 超级网申是 **WonderCV 官方、对目标招聘站仍是第三方**。填企业官网表单，冲突看该司 ATS 协议；若注入智联 / 51Job 页面，与这两站「未经许可不得用插件接入」直接冲突。
- 公开页**未找到**四站自述「插件投的简历进垃圾池」。能钉死的后果是：停服、封号、限制收发。HR 把海量模板招呼当垃圾，是产品设计下的常见结果，不是平台明文「垃圾池规则」。

| Boss 直投 | 找到，**官方校招岗位类型，不是插件** |
| 投投马 | 找到，第三方自动打招呼 / 投递扩展 |
| 一键职达 | 找到，第三方桌面客户端，自动投 + 打招呼 + 自动登录 |

## 4. 若本人确认：助手只在「提交申请」站点代点提交、不打招呼——哪些仍必然违 ToS，哪些是官方填表

前提（用户侧约束，不是给工具开脱）：

- 求职者本人确认清单；
- 助手只在「提交申请」模型的站点上**代点提交**；
- **不**自动打招呼、**不**自动回复 HR。

### 4.1 即便满足上述前提，仍然必然违反目标站 ToS 的

协议禁的是未经许可的第三方工具接入 / 脚本自动操作 / 插件收发简历，**没有「只点提交、不聊天就允许」的例外。**

| 工具 | 为什么仍然违 |
|---|---|
| 任何第三方扩展 / 油猴 / 桌面客户端在**实习僧**上代点「投个简历」 | 第三节（二）明文禁插件、脚本、第三方工具收发简历、自动访问 |
| 任何第三方工具在 **Boss** 上代点「网申·直投」或代发简历 | 第八条 10 款禁未经许可的插件外挂接入；第三条禁第三方收发简历。官方直投必须走 Boss 自己的按钮 |
| 任何第三方工具在 **智联** 上代点「立即投递」（含校园申请表提交） | 未经书面同意不得用自动程序、脚本、软件操作 |
| 任何第三方工具在 **51Job** 上代点「立即投递」 | 未经许可使用插件、外挂接入 |
| 投投马、职投助手、BOSS海投助手、一键职达、智能求职助手、前程无忧自动投递、Super_Employee、Boss 油猴自动投 | 公开功能已含代提交或代聊，四站（或其中已点名的站）必然冲突 |
| 付费代投（要账号） | 账号外借 / 代办认证，四站都禁 |
| 牛客「一键投递全网职位」若把**目标公司官网账号**交给牛客 | 不一定违牛客自己的规则；可能违**目标官网**「账号不得交给第三方」。这不是四站插件句，但是同类账号外借 |

「我只点提交、不打招呼」**不能**把右列工具变成左列。

### 4.2 官方填表 / 官方自动投（在各自产品边界内）

| 工具 | 边界 |
|---|---|
| 牛客网申助手 | 填**企业招聘官网**表单；提交本人点。不要指望它海投 Boss / 实习僧 |
| 实习僧网申助手 | 填**企业网申**；不是实习僧站内批量投 |
| 超级网申 | 填企业网申；商店还点名智联 / 前程无忧 / 应届生——**在这三站上用它，对那三站仍是未经许可的第三方插件**。只把它用在未禁插件、或未把超级网申列为禁止对象的**企业官网 ATS**时，才落在「官方填表产品、目标站冲突未证实」 |
| 智联智能投递 | 仅智联职位优选，每日最多 5，7 日，官方自动投申请，不代聊 |
| Boss 网申·直投 | 仅带该标识的校招岗，走官方按钮，不是插件 |

### 4.3 第三方「只填表」在四站上的位置

求职方舟、TalenCat、塔塔网申、一念职达：

- 填**企业官网 ATS**：四站插件句管不到（管的是这四站自己的页面）。目标公司若禁插件，仍冲突。
- 填 **智联 / 51Job / 实习僧 / Boss 自己的表单或职位页**：即使提交仍是人手点，扩展已经「接入、访问、读取页面」，落在禁插件句里。**必然违 ToS。**
- 因此：想「只在提交申请站点代点提交」时，**没有合规的第三方代点工具。** 合规加速是：官方填表插件填企业 ATS + 本人点提交；或智联官方智能投递；或四站人手点投。

### 4.4 不要做的事（重复，防止被读成用法）

- 不要把账号密码交给代投或「自动登录」客户端。
- 不要用脚本 / 扩展自动开聊或自动回复 HR。
- 不要以为改点击频率、用指纹浏览器、或「看起来像人」能让外挂变合法。
- 不要把 GitHub README 当官方许可。MIT / GPL 只约束代码版权，不授权违反网站 ToS。

## 5. 风险（不写规避）

| 风险 | 能回溯到的依据 | 写不出的部分 |
|---|---|---|
| 封号 / 停服 / 限制收发 | 四站协议都把插件、脚本、第三方登录、账号外借列为可处理事项 | 具体触发阈值、验证码策略、检测实现——公开页没有，也不应去探 |
| 「简历进垃圾池」 | **公开页未找到**平台规则写「插件投递的简历进入垃圾池」。能说的是：Boss 开聊模型下，海量模板招呼会被 HR 当垃圾会话；投递量异常可能被平台限流 | 不能写成「一定进垃圾池」或「怎样才不进」 |
| 账号被盗 / 简历泄露 | 职投助手商店披露收集 authentication information；一键职达自动登录；油猴与宽权限扩展可读已登录站全部数据；GitHub 脚本可把 JD / 简历发给第三方模型 | 不评估某个扩展「现在有没有后门」 |
